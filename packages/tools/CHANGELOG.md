# @volund/tools

## 0.1.0

### Minor Changes

- 322c399: Add atomic MultiEdit transactions, session-scoped file backups, conflict-safe restore and durable resume recovery.
- d90cf18: Add an offline, provider-neutral WebSearch contract with permission gating, redacted audit metadata, bounded normalized results, cancellation, retry policy, and untrusted output wrapping.
- 976eb21: Add the L1 tool, permission, context, prompt, session, configuration, credential, and local telemetry runtime.
- 8521920: Add WebFetch with origin-scoped permission caching, per-hop DNS and SSRF validation, pinned
  connections, bounded text responses, cancellation, rate limiting, and redacted audit events.
- d631d20: Add the built-in Task tool and an isolated three-level subagent runtime with injected RunnerFactory, bounded budgets and concurrency, cancellation cascading, tagged event bubbling, and untrusted result handling.
