# Volund CLI v0.1.0 draft release notes

Status: **blocked; not published**.

The current L1 foundation includes a typed runner/provider/tool pipeline,
permission-aware tools, session storage, CLI integration, and native sandbox
workers. The L1 user documentation site is now part of the release candidate.
This draft is not a release declaration. See `L1-READINESS.md` for the
independent audit, `L1-DOGFOOD.md` for the blocked Anthropic run, and
`L1-SIGNOFF.md` for the pending human decisions. The executable verification
procedure and evidence manifest are defined in `L1-FINAL-VERIFICATION.md`.

  been exercised with an authorized production credential.

  not substituted for a runtime tier or escape-suite execution.

  workflow supplies a Pages URL.
- npm publication and the Git tag remain intentionally absent.
