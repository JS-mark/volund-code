# Volund CLI API

> **Compatibility identifiers:** Volund CLI is the current product and command name. Public
> TypeScript symbols, schema IDs, environment variables, manifest keys, and on-disk paths in this
> reference use the `volund` / `VOLUND` machine spellings, which are frozen v1 compatibility ABI
> and change only through a versioned compatibility migration. Apollo-era legacy identifiers
> (`apollo`, `APOLLO_*`, `~/.apollo`, `apollo-code`, `@apollo-code`) are recorded in
> `productIdentity.compatibility` and must stay readable during the staged migration.

This reference is generated from the exported TypeScript API. For end-user commands and examples,
use `volund` and the `volund-cli` npm package.
